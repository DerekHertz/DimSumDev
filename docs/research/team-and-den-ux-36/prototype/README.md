# THROWAWAY H13 feasibility proof — never merge

Base: `993523f244483f554079ece4ebb07c4c9ff8e93c`. This branch contains only new prototype artifacts. Original production sources, tests, fixture definitions, resident order, real rigs, inflation, navigation, work ceilings and original assertions remain unchanged on disk.

Question: can permanent complete local two-way home witnesses plus transactionally protected actual outgoing/return routes support every original fixture resident, the unchanged late visitor caller, and an outing/newcomer/cancel/return, within the existing shared bounds?

`h13-build.mjs` statically copies/transforms exact source anchors into marked overlays. `provenance.json` records the exact unchanged and transformed SHA256 hashes. `h13-loader.mjs` checks both hashes and substitutes only the recorded module text at original module URLs. Its actors overlay adds only a read-only world observation for independent query counting. Its allocation overlay exposes only read-only counters; all limits and cumulative phases remain unchanged. `fixture.prototype.mjs` contains the original actors fixture body byte for byte, with explicit unchanged-source imports.

The places overlay constructs a two-way local witness directly at a no-approach candidate; authored approaches retain their full mandatory waypoint/extension logic. The existing registry owns all homes/destinations. Existing private `exits` records hold local and active geometry. Destination allocation, actual outgoing and destination-to-retained-home routes share work. The existing traveller consumes the proved route through one internal callback; motion still sweeps, yields and waits. Failed cancellation retains old corridor geometry and waits for a meaningful change before trying the pending return. Home arrival drops trip-only protection. No graph, second travel engine or dependency is added.

`h13-proof.mjs` checks the full actual 32-resident caller before proceeding. It checks exact original visitor identities/skeleton/first motion/leg deformation, fitting owned start/home, eventual arrival and removal to32. It then observes actual outing motion, allocates a newcomer during it, verifies independent segment clearance from protected paths, cancels away with a deliberately disconnected but body/home-safe return, checks safe retention and later home arrival, then checks a locally safe but disconnected outing. Independent footprint, dense swept-segment, simultaneous pairwise, actual deformed rig envelope and external query oracles accompany the caller.

Only after this entire caller passes, the same command invokes the four original safety test files with the unchanged H11 selectors plus existing reduced-motion solid/overhead selectors and concurrency2. The wrapper kills its owned process group on the first test failure or at60 seconds. It refuses to overwrite logs, records literal argv/hashes/exit/timing/process-group receipt, and never retries.

Sole behavioral command: `node docs/research/team-and-den-ux-36/prototype/h13-run.mjs`.

The original primary-home fallback test may encode the superseded requirement to connect an otherwise locally fitting no-approach home to central staging. It remains untouched and selected.
